# System Invariants

These 17 invariants are **non-negotiable architectural laws** enforced directly in production code and locked down by automated tests.

| # | Invariant | Code Enforcement | Automated Verification |
| :---: | :--- | :--- | :--- |
| **1** | **Explicit Approval Required:** No remote write executes without an explicitly approved immutable `DRAFT` `plan_id` and non-`DRY_RUN` mode. | `planner.py:approve_plan`, `executor.py:execute_plan`, `cli.py` | `test_scenarios_e2e.py`, `test_audit_regressions.py::test_r4`, `test_r11` |
| **2** | **Account & Endpoint Isolation:** `--mode mock` refuses non-loopback; `--mode live` requires `https://api.sandbar.com/mcp`; bound `account_id` must match live session. | `security.py:validate_endpoint_url`, `auth.py:AccountBindingManager`, `executor.py` | `test_security.py`, `test_scenarios_e2e.py` (Scenario H), `test_audit_regressions.py::test_r11` |
| **3** | **Single-Folder `Memory` Isolation:** Never touches unrelated user folders, Logs, instructions, or briefings; blocks on duplicate `Memory` folders. | `planner.py`, `executor.py` | `test_scenarios_e2e.py` (Scenarios I & J), `test_audit_regressions.py::test_r6` |
| **4** | **Durable Pre-Dispatch Journaling:** Every write transitions `REQUEST_PREPARED -> REQUEST_IN_FLIGHT` in SQLite (`synchronous=FULL`) before touching the network. | `executor.py:OperationJournal` | `test_fault_injection.py` (all 8 crash boundaries) |
| **5** | **Fail-Closed Ambiguity:** Unclear write outcomes (drops, crashes, 5xx, malformed JSON, raw `isError=True`, unknown write errors) transition strictly to `UNCERTAIN_REMOTE_OUTCOME`. | `mcp_adapter.py`, `executor.py`, `state_machine.py` | `test_scenarios_e2e.py` (Scenarios D & E), `test_audit_regressions.py::test_r2` |
| **6** | **Zero Blind Re-Dispatch (Including Multi-Hop):** Once dispatched, acknowledged, paused in verification, or uncertain, no transition path exists back to `READY` or `REQUEST_IN_FLIGHT`. | `state_machine.py` (18 states, 324 pairs), `mcp_adapter.py` (`retries=0`, `max_redirects=0`) | `test_state_machine.py` (Hypothesis 200 traces), `test_audit_regressions.py::test_r1` |
| **7** | **Acknowledgment != Verification:** `REQUEST_IN_FLIGHT` cannot jump straight to `VERIFIED`; every write must pass explicit read-after-write postcondition verification. | `state_machine.py`, `executor.py:_verify_operation` | `test_state_machine.py`, `test_fault_injection.py`, `test_scenarios_e2e.py` (Scenario F) |
| **8** | **Conservative Word & Char Limits:** Every compiled Log obeys `<= 900` conservative words (incl. `2 * title_words`) with zero dropped tokens; folder instruction obeys `<= 140` chars. | `compiler.py:count_words_dual`, `semantic_split_log`, `validate_log_payload` | `test_unit_core.py`, `test_properties.py` (Hypothesis) |
| **9** | **Deterministic Compilation & Revision Freshness:** Compilation is order-independent; duplicate titles fail closed; stale compiled artifacts fail closed in export, plan, and execute. | `compiler.py`, `exporter.py`, `planner.py`, `executor.py` | `test_properties.py`, `test_audit_regressions.py::test_r12_r13`, `test_r17_r18_r19` |
| **10** | **Privacy & Secret Non-Leakage:** Hard-blocked PII/secrets/injections (including NFKC + zero-width obfuscation and metadata smuggling) can never enter compiled outputs or remote payloads. | `privacy.py`, `security.py`, `ingestion.py`, `registry.py` | `test_properties.py`, `test_security.py`, `test_audit_regressions.py::test_r12_r13` |
| **11** | **Temporal & Evidence Integrity:** Older lower-authority evidence never supersedes newer confirmed information; open contradictions block compilation. | `reconciliation.py`, `compiler.py` | `test_properties.py`, `test_unit_core.py`, `test_audit_regressions.py::test_r17_r18_r19` |
| **12** | **Single-Writer Account Concurrency:** Exclusive kernel POSIX `flock` scoped to `canonical_account_scope` serializes `apply`, `resume`, `approve`, `cancel`, and `restore` across processes and profiles. | `locking.py:AccountWriterLock` | `test_concurrency.py`, `test_audit_regressions.py::test_r4`, `test_r10` |
| **13** | **Schema Drift Protection:** Live `tools/list` SHA-256 fingerprint mismatch invalidates the plan and halts before any mutation. | `capabilities.py`, `executor.py` | `test_scenarios_e2e.py` (Scenario L) |
| **14** | **Conservative Persistent Rate Limiting:** Account-wide >= 2.0s spacing, monotonic in-process pacing, SQLite persisted floor (clamped `<= 3600s`), never shortening `Retry-After`. | `rate_limit.py:AccountRateScheduler` | `test_rate_limit.py`, `test_audit_regressions.py::test_r10` |
| **15** | **Hard Request Budgets:** Every run enforces finite caps on writes, verification polls, reconciliation calls, retries, and consecutive errors. | `rate_limit.py:BudgetTracker` | `test_rate_limit.py`, `test_scale_soak.py` |
| **16** | **Completion Honesty:** Plans never report `COMPLETED` while any operation is pending, uncertain, paused, blocked, conflicted, or failed. | `executor.py:_summarize_plan`, `status.py` | `test_scenarios_e2e.py`, `test_audit_regressions.py::test_r10` |
| **17** | **Zero Silent Data Destruction:** Corrupted DBs are never recreated; invalid/foreign backups fail validation before touching live DB; Keychain failures never silently fall back to plaintext files. | `db.py`, `auth.py:SecureTokenStorage` | `test_persistence.py`, `test_audit_regressions.py::test_r14`, `test_r15` |
