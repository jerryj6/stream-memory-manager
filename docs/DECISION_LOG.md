# Architectural Decision Log

| ADR | Date | Decision | Rationale & Alternatives Rejected |
| :--- | :---: | :--- | :--- |
| **ADR-001** | 2026-11-23 | **Python 3.12 + `uv` + SQLite WAL + Pydantic + Typer + Official `mcp==2.3.0`** | Native support for official Anthropic/MCP Python SDK, built-in zero-dependency SQLite WAL + Online Backup, `mypy --strict`, Hypothesis property & stateful testing, and `keyring`. Rejected Node/TS (heavier native SQLite/keyring packaging) and external DB servers (unnecessary operational complexity). |
| **ADR-002** | 2026-11-23 | **Single Flat Dedicated `Memory` Folder** | Sandbar Stream does not support nested folders and caps active folders at 25. Using one `Memory` folder with category-prefixed titles (`CATEGORY — Subject`), a `<= 140`-char folder instruction, and a generated `CORE — Knowledge Index` Log avoids folder clutter while preserving high searchability. |
| **ADR-003** | 2026-11-23 | **Conservative `<= 900` Word Ceiling (Dual Counter + `2 * title_words`)** | Sandbar enforces 1,000 words incl. title without specifying exact tokenization. Dual counting (whitespace + conservative punctuation/CJK) with a 100-word safety buffer and atomic Markdown block splitting prevents server rejections and dropped tokens. |
| **ADR-004** | 2026-11-23 | **18-State Formal Operation State Machine with Dedicated Post-Write Verification Pause States** | Independent adversarial audit (R1) proved that reusing pre-write `PAUSED_AUTHORIZATION`/`PAUSED_RATE_LIMIT` during post-write verification created a 2-hop re-dispatch path on `resume` and false `CANCELLED_BEFORE_WRITE` on `pause`. Adding `PAUSED_VERIFICATION_AUTH` and `PAUSED_VERIFICATION_RATE_LIMIT` and removing `CANCELLED_BEFORE_WRITE` from `BLOCKED`/`CONFLICTED` mathematically eliminates all multi-hop post-write re-dispatch and false cancellation paths (verified by Hypothesis across 200 traces). |
| **ADR-005** | 2026-11-23 | **Zero-Retry, Zero-Redirect MCP Write Transport (`retries=0`, `follow_redirects=False`, `max_redirects=0`)** | `mcp==2.3.0` `stream_within_origin` follows same-origin 307/308 POST redirects despite `follow_redirects=False`. Setting `max_redirects=0` on the MCP adapter prevents silent duplicate writes, while omitting `max_redirects=0` on the multi-step interactive `OAuthClientProvider` client prevents `httpx2.TooManyRedirects` during legitimate OAuth discovery. |
| **ADR-006** | 2026-11-23 | **Scoped `httpx2` Response Hook + Recursive `BaseExceptionGroup` Unwrapping** | `mcp==2.3.0` swallows HTTP `401`/`429` and `Retry-After` inside nested `ExceptionGroup([MCPError(-32603)])`. Recording only `POST` JSON-RPC target calls on `self.server_url` restores exact `401`/`429`/`Retry-After` classification without leaking `GET /mcp` 405 noise. |
| **ADR-007** | 2026-11-23 | **POSIX Kernel `fcntl.flock` Scoped to `canonical_account_scope`** | Eliminates PID-file timeout races and stale lock bugs (kernel releases lock instantly on `SIGKILL`), while canonical scoping serializes concurrent profiles targeting the same remote Sandbar account. |
| **ADR-008** | 2026-11-23 | **Fail-Closed OS Keychain with Explicit Opt-In `--file-token-store`** | Silent fallback from Keychain errors to plaintext disk files risks unexpected credential exposure (Audit R14). Failing closed forces explicit operator consent before writing `0600` token files. |
| **ADR-009** | 2026-11-23 | **Zero Personal or Collaborator Literals in Tracked Repository; Owner-Local Gitignored Rules (`data/local_*.json`)** | Keeps `src/`, `tests/`, and `docs/` 100% safe for version control and independent code audits while still enforcing user-specific confidential exclusions and custom local BM25 eval queries at runtime. |
| **ADR-010** | 2026-11-23 | **Explicit `is_offline_assumption` Flag & Per-`artifact_key` Multi-Part Tracking** | Prevents confusing an intentionally emptied live `Memory` folder with an offline dry-run, prevents multi-part split Logs from clobbering one another's `remote_id`, and enables exact `MANUAL_DELETION_REQUIRED` emission when a record shrinks in part count. |
| **ADR-011** | 2026-11-23 | **Strict Separation of Local BM25 Simulation vs Native Stream Conversational Evaluation** | Prevents epistemic inflation: local BM25 scores are stamped `LOCAL_BM25_SIMULATION_ONLY`, while native Stream usefulness uses a 12-dimension manual rubric scored only after real Stream conversations. |
| **ADR-012** | 2026-11-23 | **Real-Data Refinement of `_infer_status` & Exportable-Status Filtering** | Running on the real V2 export caught that meta-record `13-01` ("Historical, superseded and contradictory context") was misclassified as `SUPERSEDED` due to the bare word `"superseded"` in its heading. Tightening `_infer_status` to match explicit `status: superseded` / `superseded by` and skipping non-exportable statuses during `--approve-all-clean` / `compile` resolved it cleanly. |
