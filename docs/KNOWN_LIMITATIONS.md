# Known Limitations (Honest Platform & Scope Boundaries)

Stream Memory Manager intentionally refuses to use undocumented private endpoints, browser scraping, mobile API reverse engineering, or credential extraction to work around official Sandbar platform limits. Every limitation below is surfaced honestly in code, CLI output, and plans:

1. **No Remote Deletion via MCP:** Official Sandbar MCP does not expose tools to delete Logs, Lists, or Folders. Created Logs/Folders are non-reversible through MCP and require manual cleanup in the Sandbar Stream app (`MANUAL_DELETION_REQUIRED`).
2. **No Documented Log-Body Editing in Baseline MCP Schema:** The Nov 8 Support KB documents `set_note_folder` (moving a note between folders) and `update_folder`, but no note-body edit tool. Unless live `tools/list` confirms an update tool, revising a previously synced Log emits `MANUAL_REPLACEMENT_REQUIRED`.
3. **Flat Folders Only:** Sandbar Stream does not support nested folders. All memory organization uses a single `Memory` folder with category-prefixed titles and a generated `CORE — Knowledge Index` Log.
4. **Briefing Tool Schema Unconfirmed Offline:** Sandbar's Nov 20 docs mention a turn-level "briefing," but its exact tool names, read capability, and character/word limits are unverified until Phase E live `tools/list`. The planner fails closed and omits `SET_BRIEFING` until both read and write briefing tools are confirmed live and existing user content is verified empty or manager-owned.
5. **No Mathematical Exactly-Once Guarantee Without Server Idempotency Keys:** If a TCP reset or client crash occurs after the server commits `create_note` and before acknowledgment arrives — AND the server suppresses or delays visibility beyond reconciliation — the system halts (`BLOCKED`) rather than risking duplicate creation.
6. **No Automated Native Stream Conversational Testing via MCP:** Official MCP does not expose a tool to initiate native Stream chat or voice turns. Local BM25 evaluation tests lexical retrievability offline only; genuine conversational usefulness requires manual execution of the 12-dimension evaluation rubric in Phase J.
7. **Token Lifetimes Require Periodic Human Re-Authentication:** Sandbar access tokens expire after 1 hour, refresh tokens after 30 days of inactivity, and connections after 90 days maximum (`auth login` required on renewal).
8. **Unencrypted Local SQLite & Review Exports:** Local SQLite DB, backups, and `data/review/` exports are protected by OS filesystem permissions (`0700`/`0600`) and full-disk encryption (FileVault on macOS), not application-layer SQLCipher encryption. Keep `data/` strictly local and gitignored.
9. **Source Export Coverage:** Two verified personal/technical export files exist on disk (`Stream_Consolidated_Archive.md` and `phase_two_final.md`); standalone ChatGPT V1 and pre-merged exports were absent on disk and were not fabricated.
